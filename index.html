Arduino Button & LED

Arduino Uno • Wokwi Beginner Project

A simple Arduino project where a push button controls a red LED. When the button is pressed, the Arduino detects the input and turns the LED on. When the button is released, the LED turns off.

💻 Arduino Code

void setup() {
  pinMode(13, OUTPUT);
  pinMode(2, INPUT_PULLUP);
}

void loop() {
  int buttonState = digitalRead(2);

  if (buttonState == LOW) {
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}
